# V1.2.1 参考保真门禁

本门禁来自 V1.2.0 的 16 条用户评价，适用于所有生成适配器。

## 必须建立的参考指纹

- 吸睛前贴：镜头、台词结构、因果、情绪和结束时间。
- 剧情机制：角色、关系、冲突、转折、商品介入、证明和回报。
- 口播：逐时间段覆盖，以及 speaker、视角、音色、音高、字速、语气、口语化程度和情绪。
- 字幕：逐段卖点覆盖，责任源只能是模型、后期包装、源轨或无字幕之一。
- 人物：数量、外观、服装、站位、景别、视线和跨分段身份。
- 音画：BGM 情绪/节奏/作用，关键手部动作、对象、数量、顺序和证明功能。
- 时长：参考总时长、钩子时长和最低比例；用户无另行要求时最低比例为 85%。
- SKU：可见结构、领型、轮廓、颜色、包装，以及肩带/提手/闭合/部件数量和禁止出现的结构。

## 生成前门禁

- 吸睛前贴、语言结构和剧情因果不得在压缩中消失；剧情型参考不可变成普通口播展示。
- 参考哪些段有口播或字幕，生成对应段就必须覆盖；整条“有声音/有字幕”不能替代逐段检查。
- 同一人物跨多个生成段时，复用同一个角色三视图、设定图或等价身份资产。只有文字“同一位”不足以证明绑定。
- 模型烧字幕时禁止后期再叠字幕；后期字幕开启时，生成 Prompt 必须明确禁止模型烧字。
- 每段 Prompt 重复相关的 SKU 几何数量和禁止结构。
- 参考 BGM、关键动作、人物站位、景别和声音画像进入每段计划。

## 成片门禁

出现下列任一问题即 `needs_revision`：前贴或剧情链缺失；前后半程口播缺失；字幕卖点覆盖不足；双层字幕；同一人物跨段漂移；音色、站位或构图无理由重置；BGM/关键动作回退；时长低于最低比例；商品出现错误几何结构。无法观察则 `needs_review`，不能以技术可播放替代语义验收。
