# v1.0.0 验证记录与边界

日期：2026-09-23。源于本项目五组已实际执行的视频实验，技能化后新增通用脚本；本轮没有发起新的付费视频生成。

## 已验证

- 系统 skill-creator 的 quick_validate 通过：frontmatter/命名/入口结构有效。校验器需要 PyYAML；技能运行脚本本身不需要它。
- 当前小云雀 CLI 实际只读 `model describe Seedance_2.5` 通过，使用本包 xyq_adapter 包装；模型模式/时长/输入限制与文档快照一致。原始响应存项目任务档案，不作为永久能力常量分发。
- Python unittest **18 项通过**：合法时长取整及超限、1–3 方案、PID 泄漏/缺素材/非法时长、依赖顺序、拒绝猜测编辑参数、首尾帧顺序与素材组合、Prompt 无 shell 执行、防重复提交、结果不明阻止重提、结束但错误/文件缺失不算成功、抽帧/预算、精确 CFR 拼接＋音频包哈希、源片不足拒绝补帧、分段新音轨拼接不引入视频 PTS 缺口、裁切/无声输出、追加清单幂等/冲突及保护评价、凭据/签名 URL 脱敏。
- 媒体测试使用 FFmpeg 合成视频和音频；提交/查询使用 mock，未访问付费生成端点。首轮路径测试暴露 macOS /var 与 /private/var 别名差异，测试改为 resolve 后通过。
- 历史真实流程覆盖图＋视频参考、图＋时间轴、两段组装、复制源 AAC、跨品类三方案、图像锚点＋首尾帧、当前平台多方法/版本/评价。历史人工脚本与本包通用脚本不是同一个程序，不能把历史调用说成本包新生成测试。

运行离线回归：

```text
python3 -m unittest discover -s <技能目录>/scripts -p 'test_*.py' -v
```

## 未覆盖 / 使用边界

- 其他 Agent、其他理解 API、其他视频生成服务尚未真实接入；提供完整接口语义和迁移步骤，不保证零配置通用。需要宿主有工具/认证并完成适配回归。
- 编辑模式历史参数冲突未解决；当前执行适配器只实现参考生成与双图首尾帧，不能把其余模式当已验证。
- 测试不证明创意效果、商品身份准确、语音自然或口型同步。人工视觉/声音 QA 仍必要。
- CFR 拼接工具只支持已一致的画面尺寸；VFR、复杂字幕、变速、空间重构需等价媒体适配器并明确记录。不能静默规范化冒充严格原片一致。
- 基础计划校验器不涵盖所有供应商限制；Agent 须按实时能力逐项检查输入数量、时长总量、像素、FPS、大小、模式与比例。
- 本地提交状态防止同目录重复；不支持服务端全局幂等。网络结果不明需核查，不能删除状态再提交。导入锁与文件原子写只协调使用同一工具的本地写入；外部并发写优先平台 API revision。
- 生成文件语义不合格可作为实验预览交付，但标 needs_revision，不声称达到 1:1 或可投放。
