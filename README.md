# Product Video Replication Skill

通用商品视频复刻 Skill（V1.2.1）。它解决的是商家每天都会遇到的一类问题：看到同行的优质创意，知道值得借鉴，却很难低成本、快速度地把它变成自己的商品视频。

## 为什么需要复刻能力？

电商创意生产很少从零开始。根据项目调研，**70% 以上的电商创意生产都基于同行的优质视频**；但人工拆解、写脚本、找素材、拍摄和后期的复刻成本很高，客户调研中的平均成本约为 **3000–4000 元/条**。这会让很多刚刚看到的好灵感，在真正落地前就失去时效。

AI 复刻的价值不是把参考视频和商品图简单丢给模型，而是把“看懂创意 → 判断能否迁移 → 选择合适的复刻程度 → 生成并验收”变成一条可执行的链路：显著降低单条视频的试错成本，也让商家能更快把已经验证过的好创意用到自己的商品上。

## Skill 解决什么问题？

它会先核对商品和参考视频，再理解画面、声音、字幕、人物关系、商品卖点和时间结构，最后根据参考与商品的相似程度路由到三种互通的能力：

### 1. 1:1 高保真复刻

适合同品类、同卖点的参考视频和商品，也适合同品裂变。尽量保留原视频的画面、口播、BGM、动作、节奏和镜头关系，只对商品做最小化改动。

### 2. 营销机制复刻

适合同品类但卖点略有差异的参考视频和商品。Skill 会理解参考视频的营销机制，例如钩子、冲突、商品介入、证明和转化，再适配新商品的独特卖点，生成结构、手法和风格相近的新视频。

### 3. 智能复刻

适合任何参考视频与商品的组合。即使品类、人物、场景和卖点差距很大，也会提取参考视频最有价值的创意手法，把它们转译为新的商品营销视频，而不是勉强声称做到了 1:1。

## 三种能力如何协同？

这不是三个彼此割裂的按钮，而是一套 **case by case 的路由机制**。对客展示三种复刻程度，是为了让商家更容易提前说明“想保留什么”；真正执行时，Skill 仍会根据商品身份、镜头适配、叙事适配、卖点适配和模型可行性做判断。

因此，用户即使选择了“1:1 高保真复刻”，如果参考视频和商品相距甚远，Skill 也会把任务路由到营销机制复刻或智能复刻，并明确说明哪些内容可以继承、哪些必须重写。相反，同品类同卖点的任务则会优先尝试视频参考生成或更严格的时间轴复刻。

典型流程是：

`核对目标 → 探查与理解参考 → 判断适配 → 选择复刻程度 → 选择技术路线 → 生成 → 后期与验收`

验收不只看“像不像”，还会检查商品是否正确、镜头和剧情是否连贯、口播与字幕是否覆盖、人物和声音是否稳定，以及输出是否真的达到了用户选择的复刻程度。

## 仓库内容

- [`SKILL.md`](SKILL.md)：Skill 入口和端到端执行规范
- [`references/`](references/)：决策树、适配器、数据契约、验收和运行示例
- [`scripts/`](scripts/)：确定性校验和计划验证工具
- `docs/`：GitHub Pages 静态流程展示，不依赖本地看板服务器或动态 API

本仓库只包含通用版，不包含千意专用版或合规版。Skill 本身是 Agent 执行规范和工具包，不是脱离模型、媒体服务和授权即可独立生成视频的 Web 应用。
